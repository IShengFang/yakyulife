# YaKy⚾Life - 棒球生涯模擬器

這是一款純文字的棒球生涯養成遊戲。玩家將從高中開始，經歷選秀、旅外、國際賽，直到引退，體驗每一次擲骰與選擇帶來的棒球人生。

點我直接遊玩👉 **[yakyolife.com](https://www.yakyolife.com/)** 

## 遊戲特色
* **多層級聯賽**：完整模擬高中、大學、業餘成棒、中職、日職與大聯盟的升降級與合約交涉。
* **隱藏屬性系統**：包含天才、鐵人等豐富的隱藏特質。
* **人生隨機事件**：感情選擇、傷病危機、公關事件與國際賽徵召，球場外的每一個決定都會影響生涯走向。
* **細緻的數據運算**：依照球探量表 (20-80) 進行能力養成，並根據不同守備位置與角色定位給予專屬評價。

## iPhone 主畫面 App 與離線遊玩

1. 用 Safari 開啟**部署此版本的網址**，選「分享 → 加入主畫面」。若有「作為網頁 App 打開」選項，請開啟。
2. 從主畫面圖示開啟一次，保持連線，等待首頁顯示「可離線遊玩」。首頁及遊戲選單的「離線遊玩與安裝」可查看下載與持久儲存狀態。
3. 完成後即可開飛航模式遊玩；正常關閉 App 或重新開機不用重下載。請在主畫面 App 內確認完成，不要只在 Safari 分頁下載。

遊戲程式、資料、圖片及操作圖示會存進裝置的 Cache Storage。網路字型為可選項，離線時使用系統字型；Discord、贊助等外部連結需要網路。**本功能保存遊戲檔案，沒有新增生涯自動存檔**；關閉後會回到開始畫面。

系統會嘗試申請持久儲存（Safari / iOS 17 起支援），核准與否會顯示在安裝說明中。網站無法保證資料永不被清除：移除 App、清除網站資料或系統儲存空間不足時，仍可能需要重新下載。請使用一般瀏覽模式。

離線檔案有新版時會先完整下載並驗證，失敗仍保留舊版。結束遊戲並關閉所有遊戲視窗 / App 後重新開啟，才會套用新版，不會在進行中的生涯強制重新整理。

開發與裝置驗證步驟見 [docs/offline.md](docs/offline.md)。
