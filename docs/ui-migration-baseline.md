## Scope

This baseline locks the current DEV implementation before visual migration. It records the existing UI entry points, runtime bindings, protected game logic areas, theme behavior, and regression checkpoints. No gameplay, RNG, formula, salary, award, Hall of Fame, retirement, or share-result behavior should be changed by UI tasks unless explicitly requested.

## Entry Points

- `index.html`
  - Loads `css/style.css?v=1.5.9`.
  - Loads ES module entry `src/main.js?v=1.5.9`.
  - Defines stable runtime DOM roots: `#start`, `#app`, `#tl-side`, `#mid`, `#board`, `#log`, `#act-side`, `#act`, `#modal`, `#alloc-full`.
  - Displays app version through `#ver-badge`, then runtime syncs from `APP_VER`.
- `src/config.js`
  - `APP_VER` is the runtime version source.
  - `SPONSOR_URL` and `OFFICIAL_URL` are shared runtime links.
- `src/main.js`
  - Initializes theme, font size, layout preference, seed, start form, timeline delegation, modal close, action collapse, and PWA manifest.
  - Starts the game from `#btn-start` by calling `seedInit(SEED)`, `setS(newState(...))`, `resetTL()`, `renderTimeline()`, `card(...)`, and `startYear()`.
